Implementation details

main() method has the command line arg parsing logic which uses the flag package.
    it also calls the pcap.FindAllDevs() to get all devices and used the first device if -i and -r is not provided.

listenFromInterface() method uses pcap.OpenLive to listen on the selected network device

readFromFile() method uses pcap.OpenOffline to read from the provided file with -r

handlePacketSource() method uses the handle and iterates over all the packets

handlePacket() method parses the packet layer by layer and then creates a string to be printed 
    with the relevant details and prints it.
