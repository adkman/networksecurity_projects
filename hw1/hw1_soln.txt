1.11 Ans:
There were total 94 HTTP GET requests made.

$ tcpdump -n -r hw1.pcap tcp and 'tcp[((tcp[12:1] & 0xf0) >> 2):4] = 0x47455420' |wc --lines
94

Here, the filter 'tcp[((tcp[12:1] & 0xf0) >> 2):4] = 0x47455420' searches for the hex value of "GET " in the packet (0x47455420).
tcp[12:1] & 0xf0 gives us the Data offset which has the header size in 32 bit words.
From that we get the location of the data where we can look for the GET request.

1.13 Ans:
Here first we need to figure out the source IP from where most of the packets were sent.

We are sorting on the src IP list and then using uniq --count to get the count of unique IP addresses. Then using sort with key to sort on the count number and then taking the last entry.
$ tcpdump -n -r hw1.pcap ip |cut --delimiter=" " --fields=3 |cut --delimiter="." --fields=1,2,3,4 |sort |uniq --count |sort -n --key=1n,1n |tail -1
11890	192.168.0.1

Hence, 192.168.0.1 is the IP address that sent most of the packets.

To figure out the brand of the device, we need to get the MAC address of the device.
We can just filter out the ARP replies and grep for the IP address.
$ tcpdump -n -r hw1.pcap arp |grep -e "192\.168\.0\.1" |grep "Reply" |head -1
14:35:49.350647 ARP, Reply 192.168.0.1 is-at c4:3d:c7:17:6f:9b, length 46

Hence, c4:3d:c7:17:6f:9b is the MAC address of the device.

Now, to get the brand of the device from MAC address, we can just grep the oui.text file.
$ grep -i c43dc7 /var/lib/ieee-data/oui.txt 
C43DC7     (base 16)            NETGEAR

Or we can just lookup the MAC address on an online OUI lookup tool like https://www.wireshark.org/tools/oui-lookup.html.

Hence, the brand of the device that sent most of the packets is NETGEAR and has the IP 192.168.0.1
